## 本版重点：支持第三方控制台 OpenRevo

- **官方控制中心（ControlCenterX）**：沿用本机 MQTT broker 模拟（`127.0.0.1:13688`，由 `GCUBridge.exe` 提供）。
- **第三方控制台 OpenRevo**：它**不使用 broker**（自己用 WinRT BLE 直连水冷坞，走 Nordic UART Service，设备名前缀 `LCTCS_`），所以本版改为**进程内内存挂钩**——在它序列化水冷状态之前，把状态结构里的 `connected` / `is_flow_ok` 等字段改成「已连接」。原理与字段偏移见 [docs/适配OpenRevo.md](https://github.com/bankerly/watercool-sim/blob/main/docs/适配OpenRevo.md)。

### 行为变化（重要）

- **默认不模拟**：打开软件什么都不做，OpenRevo 依旧显示「未连接」。
- 点主界面 **「启动模拟」** → 同时开始两条模拟；点 **「停止模拟」** → 立刻还原 OpenRevo 的内存。
- 运行中 OpenRevo 重启（或掉线）会自动重新挂钩；**没点「启动模拟」时不会动它**。
- 「软件设置 → 第三方控制台」可关闭这个联动。

### 自检适配

- 检测到 OpenRevo 时，「broker 端口不可达」不再计为问题 —— **不再弹「需要处理」提醒框**（自检 9/9 通过）。

### 安全性 / 可逆性

- **不写驱动、不修改任何控制台的磁盘文件**；OpenRevo 那条只改运行内存，停止/退出即还原原始指令。
- 若软件被强杀来不及还原：下次启动会用**磁盘镜像里的原始字节**自动还原残留挂钩。
- 挂钩前会校验目标代码处的字符串确实是 `connected`，版本不匹配则明确提示而**不会硬来**。

### 使用

1. 下载 `WaterCoolSim.exe`（单文件，**零第三方依赖**；用系统自带的 .NET Framework 4.8+）；
2. **以管理员身份运行**（托盘图标与 OpenRevo 挂钩都需要管理员）；
3. 「本机信息」页可看控制台/端口自动识别结果；「软件设置」页可改 broker 主机与端口、开机自启、托盘等。

### 已知限制

- OpenRevo 的内存挂钩点与它的版本相关，其升级后若签名匹配不到会明确提示，不会强行挂钩；
- 界面上的泵转速 `pump_rpm` 与 `MAC` 仍显示「未连接时」的值（纯外观）；
- 同一台机器上「本机当 BLE 外设」是**不可行**的（同一颗适配器不能既当中心又连自己的外设），所以同机只能走内存挂钩这条路。

> `WaterCoolSim.exe` 未做数字签名，Windows 可能提示 SmartScreen，点「更多信息 → 仍要运行」即可；需要签名版可用仓库里的 `sign.ps1` 自签。
